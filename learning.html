03

12-week curriculum (basics → React)

Har module ke end par kuch hai jo aapka apna hai — sirf topics nahi. Sequence zaroori hai: JavaScript ke bina React shuru na ho. Har module 1–2 hafte ka hai, hafte mein 3–4 ghante kaafi hain.

0Week 1

Module 0 — Setup & Tools

1 hafta · 4 ghante

Sab kuch install karna, folder structure, Live Server, Git + GitHub account, DevTools. Is module ke baghair kuch nahi hota.

VS CodeExtensionsGitGitHubNode.jsDevTools

Output: Khaali project folder jo GitHub par hai + Live Server chal raha hai.

1Week 1–2

Module 1 — HTML (structure)

2 hafte · 8 ghante

Tags, attributes, nesting, semantic tags, images, links, tables, forms, accessibility (alt, label). Har concept ke baad 3 chhoti exercises.

DoctypeSemantic tagsFormsTablesSEO basicsAlt text

Output: 3-page ki pure-HTML website (bina CSS ke) — browser mein chal rahi ho.

2Week 3–4

Module 2 — CSS (styling)

2 hafte · 10 ghante

Selectors, box model, units (px/rem/em), colors, typography, backgrounds, Flexbox, Grid, positioning, transitions, variables, Tailwind ke pehle 2 hafte.

Box modelFlexboxGridPositionTransitionsCSS variablesTailwind intro

Output: Portfolio ka poora design — desktop par 100% theek.

3Week 5

Module 3 — Responsive & Git

1 hafta · 5 ghante

Media queries, mobile-first, responsive patterns, hamburger menu, plus Git: add, commit, push, branch, merge aur GitHub Pages.

Media queriesMobile-firstclamp()Git basicsBranchesGitHub Pages

Output: Website phone par bhi perfect + pehla live deploy (free URL).

4Week 6–7

Module 4 — JavaScript Basics

2 hafte · 10 ghante

Variables, data types, conditions, loops, functions, arrays, objects, DOM, events, form validation, localStorage, fetch + API (weather app).

VariablesFunctionsArrays & ObjectsDOMEventsValidationlocalStoragefetch/API

Output: Weather app (live API se) + localStorage wala dark mode.

5Week 8

Module 5 — Project 1 + Portfolio

1 hafta · 5 ghante

Pehla bada project: full portfolio website. Uske baad apni portfolio — yehi student ka future CV banega.

Project planningFull buildSEO meta tagsAnalyticsCustom domain

Output: Apni shakl ka portfolio — apne domain par live, 6 projects ke saath.

6Week 9–10

Module 6 — React Fundamentals

2 hafte · 10 ghante

React kyun, components, JSX, props, state, useState, useEffect, lists with keys, events, Tailwind ke saath, pehla API fetch.

Vite setupJSXComponentsPropsStateuseEffectTailwind

Output: React mein rebuilt portfolio — components alag files mein.

7Week 11

Module 7 — React Router & Data

1 hafta · 5 ghante

Multi-page app (Router), custom hooks, loading aur error states, form handling, data fetch patterns.

React RouterCustom hooksLoading/Error UIData fetching

Output: 3-page ka React app with working navigation + API data.

8Week 12

Module 8 — Final Project + Deployment

1 hafta · 6 ghante

Type 10 (web app) ka chhota project — task manager / dashboard with login mock aur proper deployment.

App structureAuth UICRUDDeploy to VercelREADME

Output: React dashboard app — live URL + GitHub par source code.

05

10 common ghaltiyan — in se bachayein

Yeh har beginner karta hai. Har hafte 20 minute ka review session rakhein: sirf yehi table dikhaayein aur kahein "in 10 mein se kaun se 3 aapne kiye?" — khud ka review seekh jayega.

#GhaltiSahi tareeqa
1Sirf desktop par designMobile-first CSS — pehle phone ka layout, phir media queries
2HTML aur CSS ek saath likhnaPehle poora HTML, phir poora CSS, phir JS
3Console kholna hi nahiHar page par F12 → Console. Red error = ruk jayein
4Original size ki imagesWebP format, loading="lazy", max-width:100%
5Git use na karnaHar kaam ke baad commit — bug aaye to 1 click wapas
6File naming: final2.htmlNaam kaam ke mutabiq — about.html, style.css
7Folder structure adhooracss/, js/, images/ folders pehle se — baad mein sort karna mushkil
8Samajhe bina copy-pasteHar code block type karne ke baad 2 minute mein explain karein
9Alt text aur labels chhorr denaHar image par alt, har input par <label>
10Deploy karna hi nahiHar project ke end par deploy — doosrana tayyar karta hai, shayad nahi
