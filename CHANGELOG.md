# Changelog

## Browser-only LMS
- Removed Supabase client, configuration, SQL schema and external backend dependencies.
- Added local account registration/login using Web Crypto PBKDF2 password hashing.
- Added first-admin bootstrap in the website's Admin Console.
- Added browser-local student progress, lesson overrides and YouTube URLs.
- Added admin student/role management, manual password reset and JSON backup/restore.
- Documented single-device persistence and client-side security limitations.
