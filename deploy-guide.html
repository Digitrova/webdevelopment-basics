GitHub → Vercel — Complete Live Deploy Guide

Yeh guide un students ke liye hai jinhon ne abhi website bana li hai aur ab use live karna hai — yaani apna URL banana hai jo koi bhi khol sake.

Cheezein jo chahiye (3):

#KyaKyunKahan se
1GitHub accountWebsite ka code yahan store hota haigithub.com — free
2Vercel accountWoh service jo GitHub ka code uth kar website live karti haivercel.com — GitHub se sign up karein, free
3Git (ya GitHub Desktop)Code ko GitHub tak bhejne ka kaamgit-scm.com ya github.com/desktop
Ek hi baat samajh lein: GitHub = code ka safe khana (backup + version control). Vercel = woh jagah jahan website chalti hai. Aap code GitHub par daalte hain, Vercel usay uth kar live kar deta hai. Bas.

PART A — Local taiyari (5 minute)

A1. Check karein Git installed hai

Terminal kholein:

  • Windows: Win + R → cmd → Enter
  • Mac: Terminal app (Applications → Utilities)
  • Linux: Ctrl + Alt + T
git --version

Jawab aana chahiye jaise git version 2.43.0. Agar "command not found" aaye to Git install karein: git-scm.com → download → install (default settings).

A2. Apni website ki files check karein

my-website folder ko khol kar dekhein. Usme sirf 3 cheezein honi chahiye:

my-website/
├── index.html        ← website ka main page
├── css/style.css     ← styling
├── js/main.js        ← JavaScript
├── vercel.json       ← Vercel ka config (pehle se hai)
└── .gitignore        ← Git ka config (pehle se hai)

Zaroori: index.html folder ke andar hi ho. Agar my-website/my-website/index.html ho raha hai to ek folder zyada hai — usay theek karein.

A3. Website khol kar dekhein (sanity check)

index.html par double-click karein — browser khul jana chahiye. Styling aur buttons kaam karne chahiye. Agar kuch theek nahi hai to abhi theek karein, deploy karne ke baad nahi. Deploy ke baad har change dobara push karna padta hai.

PART B — GitHub par repository banana (10 minute)

B1. GitHub account

github.com kholein → Sign up → free account banayein. Email verify zaroor karein.

B2. Naya repository (khaali)

  1. Apne profile → top-right + → New repository
  2. Naam likhein — my-website (ya koi bhi naam)
  3. Public chunein (taake Vercel aur share dono asaan rahein)
  4. ☑️ Add a README file — UNCHECK karein (sirf is liye taake pehla push na tootte)
  5. ☑️ Add .gitignore — UNCHECK karein (humara apna .gitignore already hai)
  6. Create repository

Ab aapko ek quick setup page dikhega jisme commands diye honge — woh agli step mein kaam aayenge.

B3. Apna naam aur email Git mein set karein (ek baar)

git config --global user.name "Your Name"
git config --global user.email "ali@example.com"
Email wahi likhein jo GitHub account se jodi hui hai — warna commit "unverified" dikh jayenge.

B4. Code GitHub par bhejein

Terminal mein my-website folder ke andar jayein:

cd path/to/my-website

*(Windows par example: cd C:\Users\Ali\Desktop\my-website)*

Ab yeh commands ek-ek karke chalayein:

git init
git add .
git commit -m "Pehli website: portfolio starter"
git branch -M main
git remote add origin https://github.com/USERNAME/my-website.git
git push -u origin main
USERNAME wahan likhein jo aapke GitHub profile mein hai. .git wala folder ban jayega, .gitignore wali files automatically skip ho jayengi — yehi iska kaam hai.

B5. Auth error aaye to?

Agar git push par yeh error aaye:

fatal: could not read Username for 'https://github.com'

to aapko Personal Access Token (PAT) chahiye:

  1. GitHub → Settings (profile → Settings) → Developer settings (bottom left)
  2. Personal access tokens → Tokens (classic) → Generate new token (classic)
  3. Name likhein (vercel-deploy), Expiration: 90 days
  4. Tick karo: ☑️ repo (yeh sab se zaroori hai)
  5. Generate token → token copy karein (sirf ek baar dikhta hai)
  6. Wapas terminal mein — jab username puchhe: username = GitHub username, password = yahi token (apna asli password nahi!)
Aasan raasta (recommended): agar terminal se pareshan ho to GitHub Desktop install kar lein (github.com/desktop). Woh poori Git ki jagah le leta hai — aap bas folder kholte hain aur "Publish branch" button daba dete hain. B4 ka kaam 3 clicks mein ho jata hai.

Verify: browser mein apna GitHub repo kholein — index.html, css/, js/ wahan honi chahiye. ✅

PART C — Vercel se live karna (10 minute)

C1. Vercel account

vercel.com kholein → Sign Up → Continue with GitHub se sign up karein (wahi GitHub account jo upar use kiya).

Zaroori: Vercel ko apne GitHub ka access chahiye — is liye "Continue with GitHub" zaroor chunein, email se nahi. Sign up ke baad GitHub par permission prompt aayega → "Authorize Vercel".

C2. Project import karein

  1. Dashboard → "Add New…" → Project
  2. "Import" ke saath GitHub repositories ki list aayegi
  3. Apni my-website repository par Import dabayein
  4. Configure screen aayega — yeh bohat important hai:
SettingKya karein
Project NameApna naam (is se URL banti hai)
Framework PresetOther (ya auto-detect ho jaye to theek hai)
Root DirectoryKhali chhorein (kyun ke index.html repo ke root mein hai)
Install CommandKhali chhorein
Build CommandKhali chhorein ⚠️
Output DirectoryKhali chhorein ⚠️
  1. Deploy dabayein

Kyun Build/Output khali? Kyun ke yeh ek static website hai — koi build step nahi. Vercel khud index.html ko serve kar dega. Agar yahan kuch likh diya (jaise npm run build), to deploy fail ho jayega aur error aayega: *"The build command failed"*.

C3. Live URL!

30–60 second baad aapko ek URL mil jayega:

https://my-website.vercel.app

Browser mein khol kar check karein — website live hai! 🎉

C4. Har push par auto-update

Ab se jab bhi aap git push karenge, Vercel automatically naya version live kar dega. Alag se kuch karne ki zaroorat nahi.

Preview bonus: GitHub mein koi bhi branch banayein ya Pull Request kholein — Vercel ek preview URL bana deta hai, jise aap kisi ko bhej kar test karwa sakte hain bina live site ko chhere.

PART D — Apna domain (custom URL)

Vercel par free subdomain (my-website.vercel.app) already mil gaya. Ab apna asli domain (jaise mybakery.com) lagana hai:

D1. Domain khareedein

GoDaddy, Namecheap ya Hostinger se — domain ka saal ka kiraya $8–15 ke dastan hota hai. .com ya .pk lena behtar hai.

D2. Vercel mein add karein

  1. Vercel dashboard → apna project → Settings → Domains
  2. Add dabayein → apna domain likhein (mybakery.com) → Add
  3. Vercel aapko DNS settings dikha dega

D3. DNS mein point karein

Jahan se domain kharida (GoDaddy/Namecheap), wahan jaayein → Domain → Manage → DNS aur Vercel ki di hui records daalein:

TypeNameValue
A@76.76.21.21
CNAMEwwwcname.vercel-dns.com
  1. Save karein aur wapas Vercel par aayein

D4. Wait karein

DNS update hote hote 5 minute se 48 ghante lag sakte hain (aam tor par 10–30 minute). Vercel khud check karta rehta hai — jaise hi verify hoga, "Valid" ka green tick aa jayega.

SSL certificate automatic lag jata hai — https:// khud chal shuru ho jata hai.

PART F — Quick Alternative (agar Git bilkul na chal raha)

Sirf 2 minute mein, GitHub ke baghair:

npx vercel

Yeh command poora folder Vercel par upload kar deti hai aur turant live URL de deti hai. (Login ke liye email se sign up karna hoga, ya npx vercel login chala kar.)

Nuqsan: is tarah site sirf Vercel par hai — GitHub par koi copy nahi, is liye backup nahi rahega. Is liye Part B (GitHub) zaroor karein; yeh sirf "abhi live karke dekhna ho" ke liye hai.

PART G — Final Checklist

Deploy hone ke baad yeh 8 cheezein check karein:

  • Website ka URL khol kar khul rahi hai
  • Mobile par bhi theek lag rahi hai (phone ke browser mein kholein)
  • Navigation ke sab links kaam kar rahe hain
  • Dark mode button theek chal raha hai
  • Contact form validation theek chal rahi hai
  • Browser console (F12 → Console) mein koi red error nahi
  • GitHub repo mein code mojood hai (backup)
  • Apni website ka link kisi ko bhej kar test kar liya

Share karna ho to: Vercel dashboard → project → Share button se preview link copy karein, ya apna domain use karein.

Abhi karne wala kaam: Part A → B → C. Part C ke baad website live hai. Baqi sab optional hai.

Optional: GitHub Actions se auto-deploy

Agar aap Vercel ke dashboard ke bajaye GitHub Actions se deploy karna chahte hain, to is kit ka OPTIONAL-github-actions-deploy.yml file dekhein. Isko .github/workflows/deploy.yml naam se rakhein aur GitHub ke Settings → Secrets → Actions mein VERCEL_TOKEN add karein. Hoshiyat: yeh file my-website/ folder ke andar mat rakhein, warna pehle push par hi workflow error de dega (token nahi hoga). Default tareeqa (Part C) zyada simple aur mazboot hai.
